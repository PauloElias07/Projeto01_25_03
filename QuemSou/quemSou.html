Sobre o Projeto

Este projeto foi desenvolvido como parte de um estudo de desenvolvimento web utilizando Node.js para criação de um servidor HTTP simples.

A aplicação demonstra conceitos importantes como:

  • Criação de rotas no servidor
  • Organização de páginas HTML
  • Uso de CSS para estilização
  • Estruturação de um mini site de produtos

O objetivo é simular uma pequena loja virtual com páginas de produtos e navegação entre diferentes rotas.
