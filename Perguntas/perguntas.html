O que é este site?

Este site é um projeto acadêmico desenvolvido para demonstrar conceitos de desenvolvimento web utilizando Node.js.

Como acessar os produtos?

Os produtos podem ser acessados pela página principal através dos botões "Ver Produto".

Quais tecnologias foram usadas?

HTML, CSS e Node.js para criação do servidor e das rotas.

Este site é uma loja real?

Não. Ele é apenas um projeto educacional para estudo de desenvolvimento web.
